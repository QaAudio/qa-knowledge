# Move

## Take it anywhere. Create whenever. Trust your instincts.

### Highlights

#### Standalone

Up to 4 hours of music making per charge.

#### Four tracks

Set up any or all of Move's tracks in Drum Mode, Melodic Mode, or as a sampler.

#### Session Mode

Mix and match your musical ideas, using Move's pads to trigger clips.

#### Sampling

Use the built-in microphone or stereo line input to sample directly into Move — plus resample your tracks internally.

#### Repeat

Quickly create a series of repeating notes.

#### Capture

Move remembers what you just played, so you never lose an idea.

#### Parameter automation

Tweak the encoders to record dynamic changes to your sounds in real time.

#### Instruments

Drum Sampler, Wavetable, Drift, Melodic Sampler

#### Effects

Reverb, Delay, Saturator, Chorus-Ensemble, Phaser-Flanger, Redux, Channel EQ, Dynamics, Auto Filter

*   64GB Internal storage
*   USB-C Port to connect to computer
*   USB-A Port to connect MIDI devices
*   Dimensions: W313.5 x D146.3 x H34mm
*   Weight: 0.97kg / 2.1lbs

## Need help?

### Do I need Ableton Live to use Move?

Move is a standalone music-making tool that’s ready to use on its own, right out of the box. No additional purchase is required. Move also comes with Ableton Live 12 Intro, so you can load Sets created on Move into Live on your computer.

### Can Move be charged via USB?

Move has one USB-C port, which can be used for charging with the power supply, or for transferring data and controlling Ableton Live on your computer. Charge is maintained while connected to a computer, if the computer’s USB-C port supplies sufficient power. [Learn more about charging](https://help.ableton.com/hc/articles/15193509831324).

### Can I use Move to control Ableton Live?

Yes, you can use Move to control Ableton Live by connecting it to your computer via USB-C. In most cases, Live will automatically configure Move as a control surface, so you can begin using it immediately. For more information, visit [Control Live Mode](https://www.ableton.com/move/manual/#control-live-mode) in the [Move user manual](https://www.ableton.com/move/manual).

### Can Move be used as a sampler?

You can record audio samples directly into Move using the built-in microphone or stereo line input – then play and process them with Drum Sampler and Melodic Sampler devices. For tutorials on Move’s sampling capabilities and other features, visit [Learn Move](https://www.ableton.com/move/learn-move/).

### Can I use Ableton Packs with Move?

Packs cannot be used on Move, but samples from your Live Sets can be transferred to Move by creating custom Drum Racks and presets in Live. Learn more about [Sets on Move](https://help.ableton.com/hc/articles/15338257784092).

### Where can I learn how to use Move?

For tutorials on Move’s features, visit [Learn Move](https://www.ableton.com/move/learn-move/). Detailed instructions for setting up and using Move can be found in the [Move user manual](https://www.ableton.com/move/manual). 

### Why does Move offer only four tracks?

Move is designed for portability and immediate music-making. Move’s processor is optimized for working with four-track Sets. By transferring Sets created on Move to Ableton Live, you can take them into the refinement, editing, and finishing stages, as well as adding complexity and additional tracks.

### What is the refund policy?

If you decide Move isn’t for you, you can return it within 30 days for a refund. For refund policies and conditions, please view Ableton’s [Refund Policy](https://help.ableton.com/hc/articles/209776525-Refund-policy).
