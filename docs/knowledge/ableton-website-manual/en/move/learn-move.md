Create a new Set, the container for your musical ideas. And switch between Sets with the Set Overview.

 [![](https://beta-ableton.imgix.net/media/kbwjc4ej/learn-video-03.avif?rmode=pad&width=160&height=120&v=1dcd6902d491070&fit=crop&auto=compress,format&format=webp)](https://www.youtube.com/embed/5Q1EHEjbuhA)

### Browsing for instruments

Select different instrument presets and effects using Move's browser.

 [![](https://beta-ableton.imgix.net/media/trynbpcc/learn-video-04.avif?rmode=pad&width=160&height=120&v=1dcd6902e8c8cf0&fit=crop&auto=compress,format&format=webp)](https://www.youtube.com/embed/CdoT5YuVO1Q)

### Sampling with the microphone

Record a sample using Move’s built-in microphone, then play it back melodically.

 [![](https://beta-ableton.imgix.net/media/d4dmnzzx/learn-video-08.avif?rmode=pad&width=160&height=120&v=1dcd6902e9fc6d0&fit=crop&auto=compress,format&format=webp)](https://www.youtube.com/embed/EJwGnDdFXBI)
