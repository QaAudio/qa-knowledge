Ableton Live 12.2 is now available as a free update for all Live 12 users. It brings a whole load of new creative features to explore: including a fully redesigned Auto Filter, a new filter type for [Roar](https://www.ableton.com/en/blog/roar-meet-live-12s-new-processing-powerhouse/), and a four-voice Chord oscillator for [Meld](https://www.ableton.com/en/blog/meld-a-look-at-live-12s-new-bi-timbral-synth/). Here are three videos to start experimenting with some of what these expanded devices have to offer.

## How to use Roar’s Dispersion filter for lo-fi warble

Learn how to add subtle lo-fi warble to your keys using Roar’s new Dispersion filter type in Side Brain’s video tutorial.

[](https://www.youtube.com/watch?v=daDkXiuHwRs)

## How to form lush chords with Meld’s new oscillator

Watch LNA Does Audio Stuff create lush chords from single MIDI notes using Meld’s new four-voice Chord oscillator.

[](https://www.youtube.com/watch?v=C_F8hQZEQt0)

## How to create a wobble bass with the new Auto Filter

See how STRANJAH creates a club-shaking wobble bass with serious stereo depth using Live 12.2’s redesigned Auto Filter.

[](https://www.youtube.com/watch?v=PKIPD8ueIXQ)
