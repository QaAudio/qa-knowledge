Generators is a set of two MIDI Tools that sit in the Clip View of a MIDI track and let you create quick musical ideas and patterns.

## Patterns

Patterns is an algorithmic drum pattern generator with dedicated algorithms for each of its six drum voices.

Using the controls for each voice, you can determine which ones will be generated and on which MIDI note. Each Voice toggle determines whether an instrument-specific pattern will be generated when clicking "Generate,” while the MIDI Note sets the note for the generated pattern.

## Sting

Sting is an expressive, improvisational acid line performance tool which generates 16-step, musically-cohesive patterns.

Think of it as a 3D pattern generator with simplified controls – one dial for note selection, and another for dynamic expression. In total, Sting can generate up to 256 unique patterns combinations of different pitches, velocities and note lengths, all controlled by the user

In addition, the Type dial morphs the notes of the sequence from rather random to acid-type sequences. The Root parameter defines the root note of the sequence, while Transpose will pitch the entire sequence. The Rate parameter sets the rate or beat division of the generated Pattern, and the Density dial controls how busy the sequence is.
